# CODEship Academy Website

Canada's Inclusive Future Skills Academy for Children

## Project Overview

This is a premium, bilingual, accessibility-first website for CODEship Academy built with Next.js, Tailwind CSS, Framer Motion, and hosted on Cloudflare Pages.

## Brand Foundation

- **Headlines**: Bebas Neue
- **Body**: Montserrat
- **Primary Navy**: #2E3246
- **Accent Yellow**: #FFD740
- **White**: #FFFFFF
- **Supporting Blue**: #3F51B5
- **Light Gray**: #F4F5F7

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase
- next-i18next (Bilingual support)
- next-seo (SEO optimization)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

```
src/
├── app/              # Next.js app directory
├── components/       # React components
├── lib/              # Utility functions
├── styles/           # Global styles
├── public/           # Static assets
└── locales/          # i18n translations
```
